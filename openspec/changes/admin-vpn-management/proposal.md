# Proposal

## Why

Сейчас VPN сотрудник получает только сам: сначала подаёт заявку в бот, ждёт одобрения, потом нажимает «Получить VPN». Без VPN Telegram в компании работает плохо, поэтому новые сотрудники застревают на первом шаге. У администратора нет ни обратного пути (завести сотрудника и выдать VPN по обращению HR или при личной встрече), ни единого места, где видно и управляется всё про VPN: ссылки, устройства, лимиты, трафик. Перевыпуск, отключение и правка лимита сейчас делаются вручную на панели 3X-UI.

## What Changes

- Новый раздел администрирования «VPN» в Lemark One (десктоп) и пункт «VPN-доступы» в Профиле PWA — только для Администратора (`user.manage`).
- Список всех активных сотрудников: VPN есть / нет / ссылка устарела, устройства «N из M», трафик за 30 дней и всего; поиск по ФИО и Telegram ID, сортировка по устройствам и трафику.
- «Добавить сотрудника»: Telegram ID + ФИО (обязательно), email и лимит устройств (необязательно). Сразу активный сотрудник с доступом к боту и выданный VPN; обработка уже существующего Telegram ID (заявка, активен, отклонён, заблокирован). Сообщения в бот не отправляются.
- Карточка сотрудника: скопировать ссылку подписки, скопировать ссылку коннектора, отправить по почте (HTML-письмо: кнопка «Подключить», ссылка, короткая инструкция, ссылки на INCY; email спрашивается, если не указан, и сохраняется), перевыпустить ссылку (полный перевыпуск ключей), отключить VPN, создать VPN, устройства (список и удаление), изменить лимит устройств.
- Флаг «VPN отключён администратором»: бот на «Получить VPN» отвечает отказом, снимается кнопкой «Создать VPN».
- Ключи AmneziaWG по числу устройств до 5: скрытые клиенты `-AWG2…-AWG5` создаются и удаляются вместе с лимитом; увольнение, перевыпуск и отключение удаляют их все.
- Ежедневный снимок счётчиков трафика панели для расчёта «за 30 дней».
- Каждое действие — в журнале аудита; ссылка подписки в журнал не пишется.

## Capabilities

### New Capabilities
- `admin-vpn-management`: управление VPN сотрудников администратором — список, добавление сотрудника с VPN, ссылки и письмо, перевыпуск, отключение и запрет, устройства и лимит, трафик за 30 дней, аудит, мобильная версия.

### Modified Capabilities
- `vpn-subscription`: ключи AmneziaWG по устройствам — число слотов равно лимиту устройств до 5 (было: фиксированно 2); вспомогательные клиенты для слотов 2…N; отзыв удаляет всех вспомогательных клиентов.

## Impact

- **API**: новый `adminVpnService` + контроллер и маршруты `/admin/vpn/*` (`user.manage`); `vpnService` (создание/отзыв со слотами до 5, перевыпуск, отключение, запрет в `getAccessFromBot`); `vpnPanelService` (лимит устройств, счётчики трафика); `userRepository` (создание сотрудника по Telegram); `emailSendService` + шаблон письма; ежедневная задача снимков в `server.ts`.
- **БД**: `VpnProfile` — список вспомогательных клиентов по слотам вместо одного `awgAux*`; `User` — флаг запрета VPN; новая таблица снимков трафика. Миграция переносит существующие `awgAuxPanelEmail/awgAuxSubId` в слот 2.
- **web**: страница «VPN» (десктоп), экран в PWA, пункт меню «Администрирование».
- **bot-employee**: текст отказа «VPN отключён администратором».
- **Панель 3X-UI**: новые вспомогательные клиенты `-AWG3…5` у сотрудников с лимитом выше 2; удаление клиентов при перевыпуске/отключении.
