# Design

## Context

См. proposal.md. Панель (3X-UI, OpenAPI `/panel/api/openapi.json`) даёт `POST /panel/api/clients/hwids/{email}` — список устройств `{id, firstSeen, lastSeen, userAgent, deviceOs, osVersion, deviceModel, fingerprint}` и `DELETE /panel/api/clients/hwids/{email}/{id}`. Автоочистки HWID в настройках панели нет (проверено 2026-10-01). `lastSeen` обновляется при каждом запросе подписки с этим HWID — приложения обновляют подписку раз в 12 ч.

## Goals / Non-Goals

**Goals:** самообслуживание сотрудника в боте; автоматическое освобождение мест; никакого доступа к чужим устройствам.

**Non-Goals:** изменение лимита устройств; очистка клиентов, заведённых на панели вручную; уведомление сотрудника об автоудалении (устройство при следующем запуске приложения зарегистрируется снова, если есть место).

## Decisions

1. **Владение проверяет API, не бот.** Эндпоинты принимают `telegramId` (как `/vpn/access`), API находит активный профиль и проверяет `subId` клиента панели (тот же принцип, что в `getOrCreateProfile`/`revokeProfile` после исправления 2026-09-30). Удаление: id устройства должен быть в текущем списке этого клиента — иначе 404. Альтернатива «бот передаёт email» отвергнута: бот не должен знать логины панели.
2. **Подтверждение в боте — двумя callback'ами** (`vpn_dev_del:<id>` → «Да/Отмена» → `vpn_dev_del_ok:<id>`), без conversation: состояние не нужно, id устройства в callback_data (числа, укладываются в 64 байта).
3. **Автоочистка — `setInterval` в `server.ts`** раз в сутки + запуск при старте, как `managerLeadRatingService`. Только профили бота (`findAllActive`) с совпадающим `subId`; порог `VPN_DEVICE_STALE_DAYS` (30). Порог ориентирован на «приложение удалено»: 30 дней с запасом перекрывают отпуск, устройство вернётся само при следующем запуске, если есть место.
4. **AmneziaWG-слоты не трогаем.** Слоты хранят хеш нашего X-HWID, а панель отдаёт лишь короткий fingerprint — сопоставлять ненадёжно; выбор слота уже переназначает самый давний при приёме нового устройства.

## Risks / Trade-offs

- [Автоочистка удалит устройство, которым долго не пользовались] → при следующем запуске приложения оно зарегистрируется снова, если есть место; порог 30 дней.
- [Сотрудник удалит устройство, которым пользуется] → приложение при следующем обновлении подписки зарегистрируется заново (если место есть) — обратимо.
- [Списки устройств — персональные данные (модель телефона)] → показываются только владельцу, в логи не пишутся.

## Migration Plan

Без миграций БД. Деплой API и бота; флаг не нужен — функциональность добавочная. Откат — откат образов.
