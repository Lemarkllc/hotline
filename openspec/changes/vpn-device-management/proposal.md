# Proposal

## Why

Панель 3X-UI ограничивает подписку двумя устройствами (HWID) и сама никогда не забывает устройство: удалённое приложение навсегда занимает место. Каждое приложение (Happ, INCY) на одном телефоне — отдельный HWID. Реальный случай 2026-09-30: сотрудник поставил INCY рядом с Happ, панель сочла его третьим устройством и отдавала 404 — INCY показывал «нет серверов». Освободить место может только администратор вручную; на проде 24 из 58 сотрудников уже на лимите, так что переход с Happ на INCY или смена телефона ломается у каждого второго.

## What Changes

- В боте сотрудника — «Мои устройства VPN»: список устройств своей подписки (приложение, ОС/модель, когда последний раз обновлялась подписка) и удаление любого из них с подтверждением.
- Новые эндпоинты API для бота (под `x-bot-service-token`, канал `EMPLOYEE`): список устройств и удаление устройства — только для собственной активной подписки сотрудника.
- Ежедневная автоочистка: устройства подписок, выданных ботом, которые не обновляли подписку дольше заданного срока (по умолчанию 30 дней, `VPN_DEVICE_STALE_DAYS`), удаляются с панели.

## Capabilities

### New Capabilities
- `vpn-devices`: просмотр и удаление устройств своей VPN-подписки сотрудником и автоматическое освобождение мест от давно неактивных устройств.

## Impact

- **API**: `vpnPanelService` (список/удаление HWID), `vpnService` (устройства своего профиля, очистка), `VpnController`, `vpnRoutes`, `validators/vpn.schema.ts`, `server.ts` (ежедневная задача), `unifiedConfig` (`VPN_DEVICE_STALE_DAYS`).
- **bot-core**: `ApiClient` — два метода.
- **bot-employee**: команда и кнопка «Мои устройства VPN», клавиатуры.
- **Панель**: удаление HWID через `DELETE /panel/api/clients/hwids/{email}/{id}` — только устройства подписок, выданных ботом.
- Слоты AmneziaWG не затрагиваются: новое устройство получает освободившийся/самый давний слот (уже реализовано).
